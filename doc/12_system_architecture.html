1. 論理構成

Browser
  |  HTTPS
  v
GitHub Pages / reFront
  |  REST API
  |  multipart(file + geminiApiKey) / JSON(lines + sha256 + structuredData)
  v
Render Web Service / reBack (Spring Boot)
  |                    |
  | HTTPS              | JDBC
  v                    v
Gemini API        Render PostgreSQL
  |                    |
  +-- lines            +-- receipt_<uuid32>
  +-- structuredData   +-- receipt_image_hash_registry
                       +-- receipt_structured_summary
                       +-- receipt_structured_item

2. 配置責務

コンポーネント責務状態
Browserファイル選択、ZIP展開、APIキー保持、画面描画一時状態のみ
GitHub Pages静的ファイル配信サーバー処理なし
Render Web Service検証、SHA計算、Gemini呼出、DB操作ステートレスAPI
Gemini API画像解析外部サービス
Render PostgreSQL解析結果・重複情報の永続化永続状態

3. 信頼境界

秘密情報となるGemini APIキーはBrowserからBackendへHTTPSで送信され、BackendからGeminiへ転送されます。PostgreSQLへは保存しません。DB資格情報はRender環境変数からBackendだけが使用します。
