1. リリース前確認

  1. 対象コミットを固定する
  2. doc/ の文書版と対象ソースが一致することを確認
  3. 秘密情報がリポジトリへ含まれないことを確認
  4. cd reFront && node --test test/smoke.test.mjs を実行
  5. Maven利用可能環境で cd reBack && mvn test を実行
  6. DB接続情報とAPP_FRONTEND_ORIGINを確認

2. Backend / DBリリース

  1. Render BlueprintからPostgreSQLとWeb Serviceを作成／更新
  2. Docker buildが成功することを確認
  3. 起動ログに致命エラーがないことを確認
  4. /api/health が200・UPを返すことを確認

3. Frontendリリース

  1. GitHub Pages対象へreFrontを反映
  2. 公開ページをhard reloadし古いJS cacheを避ける
  3. メニュー→解析画面へ遷移
  4. Backend API URLが本番Renderを向くことを確認

4. 受入確認

確認判定基準
解析実レシートで原文が表示される
保存明示ボタン押下後だけDB保存される
重複保存済み同一画像が409
一覧・詳細保存した原文が参照できる
削除選択対象が一覧から消える
APIキー画面・ログ・レスポンス・DBへ漏えいしない

5. ロールバック

  1. Frontendは直前正常コミットへ戻す
  2. BackendはRenderの直前正常デプロイへ戻す
  3. 環境変数変更を直前値へ戻す
  4. DB schema変更を伴う場合は事前バックアップ／手動復旧手順を準備
  5. healthと主要操作を再確認
