1. Frontend入力チェック

対象条件異常時
Gemini APIキーtrim後が空でない「Gemini APIキーを入力してください。」、入力欄へfocus
選択ファイル1ファイル以上「画像ファイルを1枚以上選択してください。」
直接画像先頭バイトがJPEGまたはPNG signatureJPEG/PNG/ZIPを選択する旨のエラー
ZIP構造End of Central Directory / Central Directory / Local Headerが妥当壊れたZIPとして中断
ZIP暗号化general purpose flag bit 0が0暗号化ファイル名を示して中断
ZIPエントリディレクトリ以外がjpg/jpeg/pngのみ非対応ファイル名を示して中断
ZIP圧縮method 0または8未対応圧縮方式として中断
ZIP画像展開サイズ一致かつJPEG/PNG signature画像ではないとして中断
ZIP空画像エントリが1件以上「ZIPファイルにレシート画像がありません。」

2. Backend入力チェック

対象条件HTTPcode
filenull/空でない400EMPTY_FILE
file size5,242,880 bytes以下413FILE_TOO_LARGE
Content-Typeimage/jpeg または image/png415UNSUPPORTED_MEDIA_TYPE

geminiApiKeytrim後非空400GEMINI_API_KEY_MISSING
geminiApiKey512文字以下400INVALID_GEMINI_API_KEY

tableNamereceipt_[0-9a-f]{32}500UNSAFE_TABLE_NAME（内部防御）

3. 現行実装の注意

ZIPのエントリ数・ZIPファイル自体のサイズ・展開後総サイズに明示上限はありません。5MB制限はZIP展開後、各画像をBackendへ送信した際に適用されます。
