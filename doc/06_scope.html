1. 対象範囲

領域対象
入力JPEG / PNG / JPEG・PNGのみを含むZIP
解析Gemini APIによる行テキスト＋構造化データ
重複管理SHA-256完全一致
保存PostgreSQLの動的原文テーブル、管理・構造化テーブル
参照保存済み一覧／詳細
削除選択レシートの動的テーブル、summary、hash registry
公開GitHub Pages + Render Web Service + Render PostgreSQL

2. 対象外

領域対象外内容
アカウントログイン、権限、マルチテナント
会計経費精算、仕訳、税計算、家計簿集計
画像画像の永続保管、サムネイル管理
AI人手レビュー承認フロー、学習、fine-tuning
検索店舗名・日付・金額による検索／絞込みUI
運用バックアップ自動化、監視通知、SLO/SLA保証
セキュリティマルウェアスキャン、WAF、レートリミット

3. 境界条件

本システムは「解析結果の保存・参照を行うデモ／ポートフォリオ向けWebアプリ」であり、会計・税務上の原本管理システムとしての利用を想定しません。
