1. 概要

レシート画像をGemini APIで解析し、原文行と構造化情報をPostgreSQLへ保存するWebアプリケーションです。FrontendはGitHub Pages、BackendはRender、DBはPostgreSQLを想定します。

2. ディレクトリ

receipt-analysis-main/
├─ reFront/        # HTML/CSS/JavaScript
├─ reBack/         # Java 21 / Spring Boot / Docker / Render
├─ doc/            # HTML納品ドキュメント
 過去のテスト記録
# 過去のテスト記録
├─ README.md
└─ index.html      # reFrontへredirect

3. ローカル起動

# PostgreSQLを用意
cd reBack
mvn spring-boot:run

# another terminal
cd reFront
python3 -m http.server 5051

# browser
http://localhost:5051

4. テスト

cd reFront
node --test test/smoke.test.mjs

cd ../reBack
mvn test

5. 主要API

MethodPath
GET/api/health
GET/api/receipts
GET/api/receipts/{tableName}
DELETE/api/receipts/{tableName}
POST/api/receipts/analyze
POST/api/receipts/save

6. 文書の読み方

まず「01 プロジェクト概要書」「03 要件定義書」「12 システム構成設計書」を確認し、実装詳細は13〜20、環境は21〜24、品質確認は25〜27、公開・運用は28〜30を参照してください。

デモ利用

トップページの「デモを試す」から、Gemini APIキーなしで固定のサンプルレシートを体験できます。デモはFrontend内だけで動作し、Gemini API、Backend API、PostgreSQLには接続しません。
