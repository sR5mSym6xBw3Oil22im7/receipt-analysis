1. 概要

レシート画像をGemini APIで解析し、印字行と構造化データをPostgreSQLへ保存・参照・削除するWebアプリです。APIキー不要のデモモードも備えます。

2. ディレクトリ

パス内容
reFront/GitHub Pages向けFrontend
reBack/Spring Boot Backend
doc/HTML納品ドキュメント

3. デモ利用

トップページの「デモを試す」から、Gemini APIキーなしで固定のサンプルレシートを体験できます。Gemini API、Backend API、PostgreSQLには接続しません。

4. ローカル起動

cd reBack
mvn spring-boot:run

cd ../reFront
python3 -m http.server 5051

通常解析は http://localhost:5051 から利用します。デモのみならBackendは不要です。

5. テスト

cd reFront
node --test test/smoke.test.mjs

cd ../reBack
mvn test

2026-09-19の再作成時点でFrontendは18/18 PASSです。Backendはテストコード19件を確認していますが、この環境ではMavenがないため再実行していません。

6. 主要API

MethodPath用途
GET/api/health稼働確認
GET/api/receipts一覧
GET/api/receipts/{tableName}詳細
POST/api/receipts/analyze画像解析
POST/api/receipts/save保存
DELETE/api/receipts/{tableName}原文と関連データ削除

7. 簡易ログインUIについて

login.html は保存済み一覧へ進むためのデモ向けUIで、Frontend内の固定値判定です。認証・認可機能としては使用しません。
