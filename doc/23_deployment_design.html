1. Frontend

  1. GitHubリポジトリへ reFront/ を含む対象コミットをpush
  2. GitHub Pagesの公開元をプロジェクト構成に合わせて設定
  3. 公開環境で config.js がRender API URLを選択することを確認
  4. トップ、解析、一覧の静的資産が404にならないことを確認

2. Backend / DB

  1. RenderでBlueprint Pathに reBack/render.yml を指定
  2. Web Service receipt-analysis-b8po をDocker runtimeで作成
  3. PostgreSQL receipt-analysis-psl-service を作成
  4. DB_*がfromDatabaseで注入されることを確認
  5. Health Check Path /api/health を確認
  6. デプロイログでbuild / startupを確認

3. Dockerビルド

build stageは maven:3.9.11-eclipse-temurin-21-alpine、runtimeは eclipse-temurin:21-jre-alpine です。パッケージ時は -DskipTests でJarを作成します。

4. デプロイ後確認
