1. 公開前の前提

設計・実装・テストはローカル環境で行います。ローカル環境で不具合が0件であることを確認してから、フロントエンドをGitHub Pages、バックエンドをRenderへアップロードします。

2. Mavenでのパッケージ作成

cd reBack
mvn package

pom.xmlにSpring Boot Maven Pluginが定義されています。

3. Dockerfileによるイメージ作成

docker build -t receipt-backend ./reBack

Dockerfile内ではMaven packageを実行し、生成したJARをJava 21 runtime stageへコピーします。イメージ名や配布先は例であり、リポジトリの設定で指定されていません。

4. 起動設定

実行環境にDB接続情報、ADMIN_USERNAME、ADMIN_PASSWORD_HASHを設定します。本番のHTTPS環境ではSESSION_COOKIE_SECUREをtrueにします。
