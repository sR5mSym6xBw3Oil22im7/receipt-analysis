1. 作品概要

AI画像解析とWeb API、データベースを連携し、レシート画像から文字と購買情報を抽出・保存・参照するフルスタックWebアプリケーションです。

2. 技術的な見どころ

  • GitHub Pagesの静的FrontendとRenderのSpring Boot APIを分離
  • Gemini Structured Outputで原文行と構造化データを同時取得
  • Gemini APIキーを環境変数へ固定せず、画面入力をリクエスト単位利用
  • SHA-256で画像バイト列の重複登録を防止
  • ユーザー入力を動的SQL識別子に使わずUUID＋正規表現で制限
  • ブラウザ標準APIだけでZIPのCentral Directory解析・Deflate展開
  • 解析とDB保存を別操作にし、結果確認後に明示保存
  • Node/JUnit/H2によるテストを用意

3. 担当範囲として説明できる工程

要件定義入力・AI・保存・重複
設計画面/API/DB/セキュリティ
実装Vanilla JS / Spring Boot
テストNode / JUnit / H2
公開運用GitHub Pages / Render

4. 面接での説明ポイント

「AIを呼ぶだけ」でなく、APIキーの扱い、外部APIのquota/timeout、重複データの整合性、動的テーブル名の安全性、静的FrontendとBackend間のCORSなど、実運用を意識した周辺設計まで扱った点を説明できます。

5. 今後の改善テーマ

  • 構造化商品削除の整合性改善
  • ZIP展開量制限の追加

  • 検索・集計ダッシュボード
  • 認証・権限・rate limit
  • CIでFrontend/Backend testを自動実行
