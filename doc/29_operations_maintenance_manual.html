33. 既知課題・引継ぎ事項

1. 利用手順

  1. メニューから「レシートを解析」を開く
  2. Gemini APIキーを入力
  3. JPEG/PNGまたは画像のみのZIPを選択
  4. 「解析」を押し結果を確認
  5. 内容に問題がなければ「PostgreSQLへ保存」を押す
  6. 保存済みレシートはメニューから一覧へ進み「参照」で確認
  7. 不要データはチェックして削除

2. 日常運用チェック

項目確認方法異常時
FrontendGitHub Pagesが表示できるPages設定／公開コミット確認
BackendGET /api/healthRender logs / deploy状態確認
DB一覧APIが応答Render PostgreSQL状態・接続変数確認
Gemini解析1件APIキー、quota、モデル可用性確認
認証管理画面でログインし一覧APIを確認ADMIN_USERNAME、ADMIN_PASSWORD_HASH、SESSION_COOKIE_SECUREを確認

3. よくある事象

事象原因候補対応
解析が長いRender起動待ち／Gemini応答待ち画面の経過表示を確認。210秒timeout後に再試行
quotaエラーGemini利用上限別の利用可能なAPIキーへ入替
キー拒否無効／権限不足キーキーを確認して再入力
DB保存失敗Render Postgres停止／接続問題DB状態とDB_*を確認し保存を再試行
同じ画像を登録できない保存済みSHA一致一覧から対象を削除するか別画像を利用
ZIPを開けない暗号化／非画像／圧縮方式／破損ZIPを作り直す

4. 保守作業

  • ライブラリ更新時はpom.xmlと技術選定書を同時更新
  • Geminiモデル変更時はapplication.yml・テスト・AI仕様書を更新
  • DB schema変更時は削除整合性と既存データ移行を確認
  • Frontend cache bust queryを変更した場合はsmoke testも更新
  • 既知課題は33_known_issues_handover.htmlへ追記
