1.1 認証・アクセス制御

GET /api/health、GET /api/auth/csrf、POST /api/auth/login とログイン画面は公開です。/api/receipts/** は管理者セッションを要求します。セッションがない場合は401、管理者ロールがない場合は403を返します。状態変更リクエストには X-XSRF-TOKEN ヘッダーを要求し、ログアウト後のセッションは無効になります。

MethodPath認証概要
GET/api/auth/csrf不要セッションCookieとCSRFトークンを発行
POST/api/auth/login不要（CSRF必須）環境設定済み管理者としてログイン
GET/api/auth/session管理者セッションログイン状態確認
POST/api/auth/logout管理者セッション（CSRF必須）ログアウト
