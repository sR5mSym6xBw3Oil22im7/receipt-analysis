1. Backendエラー

HTTPcodemessage（代表）発生条件
400EMPTY_FILE画像ファイルを選択してください。Backend検証
413FILE_TOO_LARGE画像ファイルのサイズが上限を超えています。Backend検証
415UNSUPPORTED_MEDIA_TYPEJPEGまたはPNG画像を指定してください。Backend検証
400MISSING_REQUEST_DATA必須のリクエスト項目がありません。multipart必須項目不足
400GEMINI_API_KEY_MISSINGGemini APIキーをWeb画面で入力してください。キー空
400INVALID_GEMINI_API_KEYGemini APIキーの形式を確認してください。キー長など
401GEMINI_API_KEY_REJECTEDGemini APIキーが無効、ブロック済み、または権限不足です。別のAPIキーを入力してください。Gemini 401/403等
429GEMINI_QUOTA_EXCEEDEDGemini APIの利用上限に達しました。…Gemini quota
422EMPTY_ANALYSIS_RESULTGeminiから解析結果を取得できませんでした。応答空
422INVALID_ANALYSIS_RESULTGeminiの解析結果が想定形式ではありません。JSON schema異常
422NO_TEXT_FOUNDレシートから文字を読み取れませんでした。正規化後0行
502/400GEMINI_API_ERRORGemini APIでレシート解析に失敗しました。等その他Geminiエラー
400FILE_READ_ERROR画像ファイルを読み込めませんでした。IOException
400EMPTY_RECEIPTレシートデータが空です。save.lines空
400INVALID_IMAGE_HASH画像ハッシュ値が不正です。sha256形式不正
409DUPLICATE_RECEIPT_IMAGE同じレシート画像は既にPostgreSQLへ登録されています。保存済みSHA
404RECEIPT_NOT_FOUND指定されたレシートが見つかりません。detail/delete
503DATABASE_ERRORPostgreSQLとの通信に失敗しました。時間をおいて再度保存してください。DataAccessException
405METHOD_NOT_ALLOWEDこのHTTPメソッドは利用できません。未対応Method
500INTERNAL_ERRORサーバー内部でエラーが発生しました。想定外例外
500UNSAFE_TABLE_NAME安全でないテーブル名が生成されました。内部防御

2. Frontend固有メッセージ

分類代表メッセージ／動作
APIキー利用上限時はキー欄へfocus/selectし次のキーへの入替を促す
解析timeoutバックエンドから応答がない旨を表示（210秒）
保存timeout通信状態確認と再度保存を促す（30秒）
ZIP破損、暗号化、非画像、未知圧縮、画像なしを個別表示
解析進捗15秒単位で経過秒と「ブラウザを閉じずにお待ちください」を表示
保存成功画像番号を含め「PostgreSQLへ保存しました。」
一覧0件時「保存済みのレシートはありません。」
削除削除件数または「削除エラー: ...」

3. エラー処理原則

  • HTTP statusと機械判定用codeを分離する
  • APIキー再入力が有効なcodeはFrontendで特別扱いする
  • 保存失敗時は解析結果を保持し再試行可能にする
  • 解析途中に失敗した場合、そこまでの成功結果は画面に残すがanalysisReady=falseとなり保存ボタンは有効化しない
