1. 選定方針

静的ホスティング可能なUI、JavaによるREST API、外部AI解析、永続DBを分離し、学習・ポートフォリオ用途でも構成を理解しやすい技術を採用しています。

2. 採用技術

層技術／バージョン用途選定理由
FrontendHTML5 / CSS / Vanilla JavaScript画面・通信・ZIP展開GitHub Pagesでサーバーサイド実行なしに配信可能
Browser APIFetch / AbortController / DecompressionStreamAPI通信・タイムアウト・ZIP展開追加ライブラリなしで現行ブラウザ機能を利用
BackendJava 21API実装LTS世代のJavaでサーバー実装
FrameworkSpring Boot 4.1.0REST / JDBC / Multipart / CORSHTTPとDB処理を定型化
AI SDKGoogle GenAI 1.67.0Gemini呼び出しStructured Outputをコードから定義
JSONGson 2.13.1Gemini応答解析Javaレコードへ変換
DatabasePostgreSQL 18（Render設定）永続保存Render BlueprintでDBとWeb Serviceを関連付け
Test DBH2（PostgreSQL mode）バックエンドテスト外部DB不要でRepositoryを検証
DeployGitHub Pages / Render / Docker公開FrontendとBackendを独立公開
TestNode.js built-in test / JUnit自動テスト軽量な静的・単体・統合検証

3. 非採用・対象外

  • React / Vue等のSPAフレームワーク：現行規模では不要
  • Bootstrap / Tailwind：独自CSSで実装済み
  • Gemini APIキーのサーバー環境変数保持：運用要件により不採用
  • 画像自体のDB／オブジェクトストレージ保存：対象外
  • ユーザー認証基盤：対象外
