レシート解析

JPEG / PNG / ZIP のレシート画像を選択し、Gemini APIキーを入力してください。ZIPは複数のレシート画像をまとめて解析できます。ZIPの中身はJPEG/PNGだけにしてください。

  1. 画像を選ぶ
  2. 解析する
  3. 内容を確認
  4. PostgreSQLへ保存

この値だけをGemini API呼び出しに使用します。APIキーは保存しません。

「解析」は文字抽出と表示だけを行い、PostgreSQLには登録しません。内容を確認後、「PostgreSQLへ保存」を押すと解析結果を保存します。
